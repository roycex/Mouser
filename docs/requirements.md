# 需求清单

> 本文件由 Harness Agent 在需求确认阶段产出，作为**全流程追溯基准**（R-XXX）。
> 项目：Mouser — Logitech Mouse Remapper（`D:\WorkSpace\mouser\Mouser`）
> 需求：通过鼠标自定义按键启动电脑上指定的程序
> 确认时间：2026-09-18

## 需求确认结论（与用户逐项确认）

| 确认项 | 结论 |
|---|---|
| 需求收集 | 在现有「按键自定义动作集」基础上，新增一种动作：按下鼠标自定义按键 → 启动本机指定程序 |
| 范围界定 | 含：启动目标注册与编辑、按钮绑定、异步启动执行、配置持久化与迁移、国际化。<br>不含：文档/文件夹打开、URL 打开、管理员权限提权运行、进程去重与窗口激活 |
| 优先级 | P0 = 程序路径 + 启动参数 + 工作目录；全部 P0 项详见下表 |
| 约束条件 | 不得阻塞鼠标 Hook 线程（沿用截图功能的 off-thread 回调模式）；`subprocess` 禁用 `shell=True`；三平台行为一致；不破坏现有动作与配置；config 需版本迁移 |
| 成功标准 | 用户可注册启动目标并绑定到任意可配置按钮；按键后目标程序按参数与工作目录启动；UI 显示目标名称；重启后配置保留；旧配置无损升级；三平台代码路径齐全 |
| 交付范围 | 设计（Preprocess → SA → Design）→ **人工确认** → 编码（Coder）→ 测试（Tester）。不含 Showcase 与 CMO |
| 测试环境 | 本机缺 PySide6/pytest 且无 .venv → 不跑自动测试，Tester 降级为静态验证 + 需人工验证项清单 |

## 非功能需求

| 需求编号 | 需求描述 | 需求类型 | 优先级 | 来源 |
|---------|---------|---------|--------|------|
| R-019 | 安全性：启动进程一律使用列表参数形式且 `shell=False`，禁止字符串拼接命令、禁止 `os.system`；路径与工作目录使用前做存在性校验 | 安全需求 | P0 | 项目工程约定（profile 出口门禁） |
| R-020 | 性能：按键到完成启动调度的开销需与现有动作同一量级（非阻塞转发），实际进程启动异步进行，不引入可感知延迟 | 性能需求 | P1 | 项目工程约定 |
| R-021 | 兼容性：不修改任何既有动作 id 与语义；不破坏现有 config 字段；新增动作在未配置目标时不影响其他功能 | 兼容性需求 | P0 | 项目工程约定 |
| R-022 | 可测试性：目标注册表 CRUD、参数解析、config 迁移等核心逻辑不与 Qt/UI 耦合，可脱离 PySide6 独立导入与单元测试 | 可测试性需求 | P1 | 本机测试环境约束 |
| R-023 | 打包一致性：新增 Python 模块与 QML 文件需同步三份 PyInstaller spec（Mouser.spec / Mouser-mac.spec / Mouser-linux.spec），保证 `tests/test_spec_coverage.py` 通过 | 可维护性需求 | P1 | 项目测试守卫 |
